# cars-eda-project
Exploratory data analysis of used cars using python ,pandas, matplotlib and seaborn
Exploratory Data Analysis of Used Cars

Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a used-car dataset to understand vehicle characteristics, selling-price distributions, and relationships between different automobile features.

Author

Bidisha Priyadarshini Dash

Batch: AI-ML

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Dataset

Car Details from CarDekho

The dataset contains automobile information such as car model, manufacturing year, selling price, kilometres driven, fuel type, seller type, transmission, and ownership.

How to Run

Install the required libraries:

pip install -r requirements.txt

Run the Python file:

python bidisha_cars_eda_project.py

Make sure the dataset is available at the file path specified in the script.
